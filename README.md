# 💕 Ceyda - Günün Sözü

Her gün Ceyda'ya özel bir güzel söz gösteren Android uygulaması.

## 🚀 GitHub'dan APK Oluşturma (Adım Adım)

### 1. GitHub'da Yeni Repo Oluştur
- [github.com/new](https://github.com/new) adresine git
- Repo adı: `ceyda-love-app` (veya istediğin bir isim)
- **Public** veya **Private** seç
- "Create repository" tıkla

### 2. Bu Dosyaları Repo'ya Yükle

**Seçenek A — Terminal ile (önerilen):**
```bash
cd ceyda-love-app
git init
git add .
git commit -m "ilk commit 💕"
git branch -M main
git remote add origin https://github.com/KULLANICI_ADIN/ceyda-love-app.git
git push -u origin main
```

**Seçenek B — GitHub web arayüzü ile:**
- Repo sayfasında "uploading an existing file" linkine tıkla
- Tüm dosya/klasörleri sürükle bırak

### 3. APK'nın Build Edilmesini Bekle
- Repo sayfasında **Actions** sekmesine git
- "Build APK" workflow'unun çalıştığını göreceksin
- Yeşil ✅ olunca tıkla
- Sayfanın altında **Artifacts** bölümünde **CeydaApp-debug** dosyasını indir

### 4. APK'yı Telefona Kur
- İndirdiğin ZIP'i aç → içinden `app-debug.apk` çıkacak
- APK'yı telefona aktar (kablo, Drive, Telegram, WhatsApp vs.)
- Telefonda aç ve "Bilinmeyen kaynaklardan yükleme"yi izin ver
- Kur ve aç! 💕
